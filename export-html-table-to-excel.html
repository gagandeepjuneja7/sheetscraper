How to export any HTML table to Excel or Google Sheets in one click

Open the page, click Auto-Detect, then download a CSV or copy the rows. No code, no selecting cells by hand, no broken formatting.

How to do it, step by step

  1. Install SheetScraper from the Chrome Web Store. It is free and needs no account.
  2. Open the page with the table and click the SheetScraper icon. The side panel opens next to the page.
  3. Click Auto-Detect Table. SheetScraper finds the main table on the page and shows it in the preview. If the page has several tables, pick the one you want from the list.
  4. Check the preview. Type in the filter box to see only the rows you need.
  5. Click CSV to download a file that opens in Excel, or Copy to Sheets and press Ctrl+V in Google Sheets or Excel. Each cell lands in its own column.

Other ways, and when to use them

Google Sheets formula. For a public page with a plain table, =IMPORTHTML("https://example.com/page", "table", 1) pulls the first table into a sheet. It fails on pages that load data with JavaScript or need you to be signed in, and it has no preview.

Excel's From Web. In Excel for Windows, Data > From Web loads tables from a URL through Power Query. It is powerful but slow to set up for a one-off copy, and it does not see pages behind a login.

SheetScraper reads the page you already have open in Chrome, including pages that load data with JavaScript and pages you are signed in to, and shows you the rows before you export.

Coming this week: native Excel (.xlsx) export and "Collect pages", which merges several pages of results into one table. Both are in Chrome Web Store review now (v1.1). Until then, CSV opens directly in Excel and Copy to Sheets pastes into Excel too.

Yes. Every feature in the free plan works up to 50 rows per scan. Pro removes the limit and adds webhook push: $30 once for lifetime, or $9 per month, taxes included. No credits and no trial.

Can I get a real .xlsx file instead of CSV?

Today SheetScraper exports CSV and JSON, and Copy to Sheets pastes straight into Excel. Native .xlsx export is in Chrome Web Store review as part of v1.1 and should be live this week.

Does my table data go to a server?

No. Detection and export run inside your browser. SheetScraper has no analytics, no ads and no servers of its own. Data leaves your device only if you set up a webhook yourself.
